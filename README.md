# CRESCENT Organization Settings

Organization-wide files for the Cascadia Region Earthquake Science Center (CRESCENT) on GitHub. GitHub applies the community files here to every repository in `cascadiaquakes` that doesn't have its own.

**Organization page:** https://github.com/cascadiaquakes
